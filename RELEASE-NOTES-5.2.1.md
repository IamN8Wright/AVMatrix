# InNasc 5.2.1

- Displays the embedded company name prominently on the company sign-in welcome page.
- Displays the selected `.nasc` device tier before sign-in, including Unlimited tiers.
- Displays a distinct license name below the tier when a company has multiple `.nasc` licenses.
- Adds safe, non-secret company identity metadata to newly saved `.nasc` login envelopes while keeping inventory and credentials encrypted.
- Falls back to the existing license name for 5.2.0 company files and identifies legacy files that still require Global Admin migration.
