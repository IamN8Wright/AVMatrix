# InNasc 5.3.7

- Company Admins can open **Manage users** in the signed-in workspace sidebar.
- Add employee logins, select an Admin/User/Read-only role, assign selected clients or all current and future clients, reset passwords, and disable or remove accounts.
- Admins always have access to every client. Users and Read-only accounts retain their selected or all-client scope. Existing Owner and Tech roles remain compatible and appear as Admin and User in the company editor.
- User changes publish to the signed-in company file or Google Drive company. A newer company revision blocks a stale editor from overwriting another employee's changes.
- Account-only saves retain the inventory merge ancestor, unfinished local device edits, configuration bytes and checkout ownership.

The last enabled company Admin is protected. A separate Global Admin executable is not required for routine company-user management. Real connected Google Drive account-management and idle/reconnect validation remain runtime checks.
