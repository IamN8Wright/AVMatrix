# AV Matrix Studio 3.1.0

- Added a visible progress window for client checkout, takeover, and check-in.
- Added explicit checked-in/checked-out status to every client card.
- Added checkout/check-in controls and lock status inside the open client workspace.
- Added Owner-managed, per-client assignments for Tech and Read-only accounts.
- Preserved inaccessible clients from the Master during full merge and push.
- Released affected checkout locks when access is revoked or an account becomes
  disabled or Read-only, with an explicit Owner warning.
- Added a Refresh NICs action to the verification toolbar.
- Moved equipment-editor field captions into the fields as placeholder text.
- Existing user accounts retain all-client access by default.
