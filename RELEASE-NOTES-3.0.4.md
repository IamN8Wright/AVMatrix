# AV Matrix Studio 3.0.4

- Increased the bottom status bar height and vertically centered both status labels so text remains fully visible at scaled Windows display settings.
- The sync indicator now follows the Master Matrix used by the active signed-in session.
- A saved but inactive local or Google Drive connection no longer keeps the active session amber.
- The sync indicator refreshes immediately after sign-in, pull, merge/push, checkout, check-in, and session changes.
